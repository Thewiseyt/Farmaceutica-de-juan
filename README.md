# Farmaceutica-de-juan
Este es un sistema básico  de un inventario de un farmacéutico que su nombre es juan

Esta es una practica basica sobre la asignatura de programacion orientada a objetos

Este programa permite lo siguiente:

Registrar medicamentos
Consultar el inventario
Vender medicamentos
Calcular el total de ventas del dia

el lenguaje que utilize fue Python
